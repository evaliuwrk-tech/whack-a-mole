# 八月半烤肉趣

中秋節烤肉小遊戲，邊烤邊學客家話（四縣腔）。

## 玩法

- 客人用客家話點菜，點對話框可以重聽
- 從木盤選食材放上烤網，烤到「剛好！」時點它送給客人；烤太久會「臭火𤊶」
- 有烤肉醬標記的菜：先按「烤肉醬」沾醬，再點烤網上的菜用「搓仔」刷
- 火變小要加「火炭」；沒人點的熟食會放到保溫盤
- 120 秒三關：看圖 → 看客語字 → 只用耳朵聽
- 首頁「食材客語圖鑑」可以逐一聽 20 個詞（🐢 慢速）

## 素材

- 食材圖：`烤肉攤.pdf` 切圖去背（`img/`）
- 發音：客家委員會臺灣客語語音資料庫 語音合成 API，四縣腔女聲 `hak-xi-TW-vs2-F01`，預先產生為 `audio/*.wav`
- 詞彙：`中秋烤肉相關詞彙.docx`；「削胖（吐司）」依詞彙表拼音 xiog pangˋ 以拼音合成
