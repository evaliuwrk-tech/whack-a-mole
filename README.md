# 咚咚打地鼠

30 秒網頁打地鼠遊戲。金髮小勇者站在草地中央，地鼠從他身邊的洞冒出來，點牠，小勇者就會衝過去一槌敲下！

**立即遊玩：** https://evaliuwrk-tech.github.io/whack-a-mole/

## 玩法

- 點冒出頭的地鼠（電腦也可以按數字鍵 1–8）
- 咖啡色地鼠 +1，戴皇冠的金地鼠 +3
- 別打炸彈！打到會 −3，小勇者還會被炸成黑炭暈一下
- 連擊 5 次、10 次有額外加分
- 每隻地鼠頭上都有數字 1–10，敲中會用客語唸出來，可選**海陸腔**或**四縣腔**（開始畫面或右上角按鈕切換）

數字語音：客家委員會「[臺灣客語語音資料庫](https://speech.hakka.gov.tw/)」語音合成（海陸腔、四縣腔女聲）。

單一 HTML 檔，不需安裝，手機和電腦都能玩。

# 鬼屋手電筒（萬聖節）

停電了！拿著手電筒在黑漆漆的鬼屋裡，聽客語找出糖仔、鬼仔、蝠婆（仔）、蝲䗁、貓仔、掃把。可選**四縣腔**或**海陸腔**，拼音以調號標示。

**立即遊玩：** https://evaliuwrk-tech.github.io/whack-a-mole/halloween/

- 開始前可以先看「單字卡」：圖片、客語、拼音、華語意思，點卡片聽發音，左右滑動換卡
- 電腦：移動滑鼠照亮；手機：手指滑動照亮、點一下抓
- **第 1 關（基礎關）**：東西不會動，60 秒內找到 8 個過關
- **第 2 關（進階關）**：東西開始會動！鬼仔會飄、貓仔走來走去、蝠婆亂飛、蝲䗁上下爬、掃把繞圈飛；還多了 3 個新單字：目珠仁（眼球）、帽仔（帽子）、手指，目珠仁會滾、帽仔會跳、手指會爬；60 秒內找到 10 個全部過關
- 過關時剩下的秒數會換成獎勵分數；解鎖後可以從首頁直接挑戰進階關
- 大鬼會不時飛過：點到牠 +20 分、+3 秒；進階關沒抓到的話，牠會把房間裡的東西吹亂
- 找對 +10，3 秒內找到再 +5，點錯扣 2 秒並告訴你那是什麼
- 結束畫面南瓜馬車從右邊駛來接你，還可以複習今晚學到的客語（附華語意思）
- 有背景音樂，可在開始畫面或右上角 🎵 開關

客語語音：客家委員會「[臺灣客語語音資料庫](https://speech.hakka.gov.tw/)」語音合成（四縣腔、海陸腔女聲）。
